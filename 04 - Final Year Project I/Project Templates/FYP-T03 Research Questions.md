## 3. Question checks (for each RQ)
- [ ] Clear: one question, no undefined terms
- [ ] Focused: the scope is bounded (who, where)
- [ ] Answerable: I know what evidence answers it
- [ ] Not a yes/no question (unless deliberately so)
- [ ] Together, the sub-questions answer the main question
