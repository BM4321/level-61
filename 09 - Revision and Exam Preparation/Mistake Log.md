# Mistake Log

Every mistake on practice, labs or mocks goes here, **with its cause**. Patterns in the "cause" column are what you fix; individual wrong answers are just symptoms.

## Cause categories
| Code | Cause | Typical fix |
|---|---|---|
| K | Knowledge gap (didn't know the fact or method) | Re-study the lesson section; add a flashcard |
| U | Understanding (knew the steps, not why) | Explain it aloud; do an L4 problem |
| P | Procedure slip (sign, unit, off-by-one, precedence) | A checklist for that step; slow down at that point |
| R | Read the question wrongly | Underline command words and constraints first |
| T | Time pressure | Timed practice; the time plan in [[Exam Technique and Assessment Strategy]] |
| C | Communication (right answer, poorly shown) | Show working; state assumptions; label units |
