# Question Bank Index

Every question bank has two questions per lesson, with folded answers; every mock has a marking guide. All are **designed practice material**, not past papers. Computed answers are checked by `09 - Revision and Exam Preparation/code/tests/` (run `python -m pytest` there): the tests import the module calculators, and for code questions they execute the snippets from the notes themselves.

## How to use the banks
1. **During the semester:** after each lesson's D+3 review ([[Review Schedule]]), answer its two bank questions closed book.
2. **Before a mock:** do a mixed set (e.g. every odd-numbered question in a bank) under time pressure.
3. **After any miss:** log it in [[Mistake Log]] with the cause code; recurring causes go to [[Weak Area Tracker]].

See [[Exam Technique and Assessment Strategy]] for time allocation and command words.
